# Heap Sort Lab — CMSC 204

## Overview
This repository contains my Heap Sort Lab for CMSC 204 (Data Structures).

The lab demonstrates how Heap Sort works by manually constructing a Max-Heap and sorting an array in ascending order.

## Lab Objectives
- Build a Max-Heap using the bottom-up approach.
- Apply the sift-down operation to maintain the Max-Heap property.
- Perform Heap Sort step by step.
- Understand how a binary heap can be represented using an array.

## Original Array
`[5, 22, 9, 76, 63, 81, 48, 92, 54, 28]`

## Final Sorted Array
`[5, 9, 22, 28, 48, 54, 63, 76, 81, 92]`

## Time Complexity
- Building a Max-Heap: O(n)
- Heap Sort: O(n log n)
